Publish

Download the two data files, then drop them into your GitHub repository. The live site updates in about a minute.

  1. Open your repository on GitHub

    Go to the repository that holds your catalogue, in the folder where index.html sits.

  2. Choose Add file, then Upload files

    Drag both downloaded files onto the page. Uploading a file that already exists simply replaces it.

  3. Commit changes

    Type a short note like "updated prices" and press the green Commit button.

  4. Wait about a minute

    GitHub Pages rebuilds the site. Refresh the catalogue and your changes are live.

Advanced — edit the raw data

Only use this if you know JSON. Paste in a full file and press Load to replace everything currently open.
